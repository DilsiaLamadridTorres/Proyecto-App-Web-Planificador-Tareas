## App Web Planificador de Tareas

Aplicación web para la gestión y planificación de tareas, desarrollada como proyecto individual del Bootcamp Full Stack Java de Generation Colombia.

##  Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)

En futuros sprints se integrará un backend con Java, Spring Boot y una base de datos SQL.

## Estructura del proyecto

```
task-planner/
│
├── frontend/
├── backend/
├── docs/
├── database/
└── README.md
```

## Funcionalidades

- Crear tareas
- Editar tareas
- Eliminar tareas
- Marcar tareas como completadas
- Gestión mediante una interfaz intuitiva

## Estado del proyecto

Sprint 1 - Desarrollo de la interfaz de usuario.
